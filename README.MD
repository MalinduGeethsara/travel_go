
# TRAVELGO 🌍

A modern, responsive travel blog website designed to inspire global exploration, promote sustainable travel, and provide expert destination guides. Built as part of Class Task 3 using the Bootstrap 5 framework.

**Live Demo:** [https://gilded-marzipan-ccda29.netlify.app/)

---

##  Features

This project demonstrates the effective use of modern UI/UX practices and responsive web design principles. Key features include:

* **Responsive Navigation:** A fully responsive Bootstrap sticky navbar linking all sections and pages seamlessly.
* **Grid System Layouts:** Adaptive layouts that look great on mobile, tablet, and desktop devices.
* **Modern UI Components:** Utilization of Bootstrap cards, badges, and custom hover animations (`transform` and `box-shadow` transitions).
* **Interactive Elements:** Multiple button styles (success, dark, outline, disabled) and embedded Google Maps for location contexts.
* **Professional Typography & Iconography:** Integrated with Google Fonts (Inter) and Bootstrap Icons for a sleek, contemporary aesthetic.

---

##  Project Structure

The website consists of four main HTML pages, designed with a cohesive green (`success`) and white theme:

1.  **`index.html` (Home):** The landing page featuring a hero section, value propositions, and an inspiration gallery.
2.  **`destinations.html`:** A grid-based showcase of famous global destinations with integrated map links.
3.  **`about.html`:** The company story, team profiles, travel style comparisons, and core values.
4.  **`contact.html`:** A professional split-layout contact page featuring contact details, an embedded map, and a user inquiry form.

3.  Open `index.html` in your preferred modern web browser.
